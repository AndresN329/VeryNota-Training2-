# 📊 VeryNota :0 - Programa de Gestión de Calificaciones

Este programa en Python permite gestionar calificaciones académicas de manera interactiva a través de consola. Fue creado como parte de un ejercicio práctico de programación básica.

---

## 🚀 ¿Qué puede hacer este programa?

El programa guía al usuario por varios pasos relacionados con el manejo de calificaciones:

### 1. ✅ Verificación de Aprobación
- El usuario ingresa una calificación entre 0 y 100.
- El sistema verifica si la calificación es aprobatoria (mayor o igual a 60) o no.

### 2. 📈 Cálculo del Promedio
- Permite al usuario ingresar varias notas separadas por comas.
- El programa calcula el promedio de esas calificaciones.
- Valida que todas estén dentro del rango de 0 a 100.
- Muestra mensajes si hay notas fuera de rango.

### 3. 📊 Comparar Calificaciones contra un Valor Específico
- Después de calcular el promedio o ingresar notas directamente, el usuario puede comparar todas las calificaciones con un valor que elija.
- El programa muestra cuántas calificaciones son mayores a ese valor y cuáles son.

---

## 🛠️ Funcionalidades Técnicas

- Validación de entradas: números, rangos válidos (0-100), separación por comas.
- Lógica de control mediante estructuras `while` y `try-except`.
- Uso de listas para almacenar y filtrar calificaciones.
- Condicionales para diferentes flujos de ejecución según las respuestas del usuario.

---

## 📚 Instrucciones de Uso

1. Ejecuta el programa en un entorno que soporte Python (por ejemplo: IDLE, VSCode, terminal).
2. Sigue las instrucciones que aparecen en pantalla:
   - Ingresa una calificación para verificar si apruebas.
   - Decide si deseas calcular un promedio.
   - Ingresa tus calificaciones separadas por comas.
   - Compara esas notas contra un valor numérico.
